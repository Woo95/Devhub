# 캐릭터 홍보용 쇼츠 기획안

---
## [목표]
- 쇼츠 영상 길이: **30초 ~ 45초**
- 게임 전체가 아닌, **캐릭터 중심 콘텐츠**로 구성
    - 모든 캐릭터를 개별 쇼츠로 제작
    - 설명 중심이 아닌, 매력으로 플레이를 유도하도록 구성
- 각 영상은 캐릭터의 핵심 매력이 한눈에 전달되도록 구성
    - 스킬 구성
    - 플레이 스타일
---
## [쇼츠 진행 순서]
### `1. 인트로`
- **시간**
	- 대략 3초
- **핵심 구성**
	- 캐릭터를 화면 중심에 크게 배치
	- 캐릭터 음성 대사로 첫인상 전달
	- 역할군 UI(탱커/딜러/힐러) 표시
	- 캐릭터 역할군 UI(탱커/딜러/힐러) 명확히 표시
- **옵션**
	- 화면 구석에 게임 로고 소형 배치
		- 아웃트로에서 크게 노출 예정 → 인트로가 복잡하면 생략
- **필수 체크**
	- 영상 초반부에 Entertainment Software Rating Board **ESRB 등급 로고 삽입 여부 확인**

### `2. 스킬 소개 (짧고 이해하기 쉽게)`
- **시간**
	- 대략 10초
- **핵심 구성**
	- 주요 스킬을 짧게 순차적으로 보여주며 이해 중심으로 전달
		- 훈련장이 아닌, 실전 전투 흐름 속에서 스킬 활용을 보여주는 방식
	- 각 스킬의 기능과 특징이 한눈에 들어오도록 구성
	- 캐릭터의 전투 스타일을 미리 암시하는 역할
- **연출 방식**
	- 스킬을 1~2초 단위로 템포감 있게 전환
	- 너무 빠르지 않게, 이해 가능한 속도 유지
	- 스킬이 잘 보이도록 과하지 않은 연출 유지
- **예시**
	- https://youtu.be/gojQHSdKxHI
		- 구간: 22초 ~ 32초

---
### `3. 플레이 스타일 (하이라이트)`
- **시간**
	- 대략 10초
- **핵심 구성**
	- 스킬 소개에서 보여준 요소들을 실제 전투 흐름 속에서 확장
	- 스킬 조합, 이동, 전투 템포 등을 통해 캐릭터가 어떻게 쓰이는지 매력을 보여주는 구간
- **연출 방식**
	- 다수 적과의 전투/난전 상황 구성
	- 스킬 연계 → 콤보 → 궁극기로 마무리
	- 템포를 높여 몰입감과 타격감 강조

---
### `4. 문구 (옵션)`
- **시간**
	- 대략 2초
- **핵심 구성**
	- 짧은 문구를 빠르게 분할 노출하여 임팩트 전달
	- 타이포그래피가 리듬감 있게 연속 등장
	- 캐릭터의 핵심 컨셉/매력을 텍스트로 직관적으로 강조
- **연출 방식**
	- 단어/문장을 끊어서 순차적으로 등장
	- 각 텍스트는 0.3 ~ 0.7초 내외로 빠르게 전환
	- 사운드(타격음, 비트)에 맞춰 싱크
- **예시**
	- https://www.youtube.com/shorts/xU7gVYksd6Q?feature=share
		- 구간: 10초 ~ 14초
	- https://youtu.be/jk6sz25OZgw

### `5. 아웃트로`
- **시간**
	- 대략 4초
- **핵심 구성**
	- 게임 로고를 크게 배치
	- 게임 제목을 명확하게 노출
	- 플랫폼 아이콘(steam) 표시로 플레이 유도
- **옵션 (필수, 택1)**
	- 전체 게임 대표 일러스트 사용
	- 해당 캐릭터와 연관된 일러스트 활용
	- 텍스트 중심 구성 (로고 + 타이틀 강조)
